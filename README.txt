Overview:
Depth is a game engine designed from the ground up for VR games development. Not AR, not MR, not for non-games, it is for specifically VR games with
light flatscreen elements.

Notes:
1. "Low-level" will be used to refer to any parts of the engine and/or game that are lower in the chain of abstraction within the engine itself, 
    not necessarily meaning closer to machine hardware.
        Ex: Rendering code in the engine is low-level compared to scripts controlling game objects to be seen.
